Si el directorio no esta vacio, mover archivos existentes (.planning, .agents, etc.) temporalmente y restaurarlos despues del scaffold, o usar un directorio temporal y copiar los archivos generados.

2. Instalar dependencias adicionales:


3. Verificar y asegurar que `tsconfig.json` tiene `"strict": true`. Si el scaffold genera `strict: false`, cambiarlo a `true`. Verificar que existe el path alias `"@/*": ["./src/*"]`.

4. En `next.config.ts`, asegurar configuracion minima y limpia. No agregar flags innecesarios — Turbopack es default en Next.js 16, no necesita `--turbopack`.

5. Crear `src/lib/utils.ts` con la funcion `cn()`:
   ```typescript
   import { type ClassValue, clsx } from 'clsx'
   import { twMerge } from 'tailwind-merge'

   export function cn(...inputs: ClassValue[]) {
     return twMerge(clsx(inputs))
   }
   ```

**IMPORTANTE:**
- Usar `bun install` y `bun run`, NUNCA `npm` ni `npx`.
- NO usar `bun --bun next dev` (incompatibilidades NAPI con Next.js 16). `bun run dev` ejecuta Node.js internamente.
- NO crear `tailwind.config.ts` — Tailwind v4 usa CSS-first config con `@theme`.
- Si create-next-app genera `tailwind.config.ts`, eliminarlo.

2. Reemplazar `src/app/layout.tsx` con el root layout configurado:

   ```typescript
   import type { Metadata } from 'next'
   import { Raleway, Montserrat } from 'next/font/google'
   import './globals.css'

   const raleway = Raleway({
     subsets: ['latin'],
     variable: '--font-heading',
     display: 'swap',
   })

   const montserrat = Montserrat({
     subsets: ['latin'],
     variable: '--font-body',
     display: 'swap',
   })

   export const metadata: Metadata = {
     title: 'Lafayette Uni For Me - Colegios',
     description: 'Catalogo de soluciones textiles para uniformes escolares',
     robots: { index: false, follow: false },
   }

   export default function RootLayout({
     children,
   }: {
     children: React.ReactNode
   }) {
     return (
       <html lang="es" className={`${raleway.variable} ${montserrat.variable}`}>
         <body>{children}</body>
       </html>
     )
   }
   ```

   Raleway para headings (geometria elegante, estilo editorial), Montserrat para body (legibilidad en specs tecnicas). Per user decision y recomendacion de RESEARCH.md.
   `robots: { index: false, follow: false }` porque es herramienta interna, no debe indexarse.
