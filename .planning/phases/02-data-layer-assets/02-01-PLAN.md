  <name>Task 2: Extraer imagenes de producto del PDF, componer canal alfa y convertir a WebP</name>

  <action>
Pipeline de 4 pasos para extraer imagenes de producto del PDF `Uniformes_Colegios.pdf`:

**Paso 1: Extraer con pdfimages (CMYK->RGB automatico)**
```bash
TEMP_DIR="/tmp/lafayette-extract"
mkdir -p "$TEMP_DIR"
pdfimages -png -p -f 4 -l 12 Uniformes_Colegios.pdf "$TEMP_DIR/img"
```
Esto extrae imagenes de las paginas 4-12 (donde estan los productos). El flag `-png` convierte CMYK a RGB automaticamente. Las imagenes salen en pares: imagen RGB + mascara alfa (smask) como archivos separados.

**Paso 2: Componer imagen + mascara alfa con Pillow**
Escribir un script Python que:
1. Lista todos los PNG extraidos en $TEMP_DIR
2. Agrupa por pagina (el nombre incluye numero de pagina)
3. Para cada par (imagen RGB + mascara gris del mismo tamano): compone usando `Image.putalpha(mask)` para crear PNG con transparencia real
4. Solo procesa imagenes grandes (>400px de ancho) -- son las fotos de producto
5. Guarda en `public/images/products/` con nombre temporal `pageNN-X.png`

CRITICO: Las imagenes del PDF tienen mascaras de transparencia reales (valores 0-255). Si se omite este paso, las imagenes tendran fondos negros o artefactos. Verificar que cada par tiene dimensiones coincidentes antes de componer.

**Paso 3: Convertir PNG a WebP**
```bash
for f in public/images/products/*.png; do
  name=$(basename "$f" .png)
  cwebp -q 80 "$f" -o "public/images/products/$name.webp"
done
```

**Paso 4: Verificar calidad**
- Verificar con `sips -g space` que las imagenes estan en RGB (no CMYK)
- Verificar con `sips -g pixelWidth` que todas son >=400px de ancho
- Verificar visualmente (abrir 2-3 imagenes) que no hay fondos negros

Despues de verificar, eliminar los PNG intermedios (mantener solo WebP en products/).

NOTA: Las imagenes saldran nombradas por pagina (page04-0.webp, page05-0.webp, etc.). El mapeo exacto imagen->tela se hara manualmente en los datos TypeScript de Plan 02, ya que el PDF usa 1-2 imagenes de producto por pagina de categoria que cubren multiples telas. Esto es esperado y esta documentado en la research (Open Question 1).

NOTA 2: Considerar tambien extraer imagenes de las paginas 13-19 (secciones de Personalizacion y Cuellos) para tenerlas listas para Phase 6. Usar rango ampliado: `-f 4 -l 19`. Estas imagenes adicionales se guardan en `public/images/content/` para diferenciarlas de producto.
