**DEBT-02: Corregir NavLinks active state**

El bug: `pathname.startsWith(item.href)` donde `item.href = '/usos'` no captura rutas `/uso/[slug]` porque `/uso/sudaderas...`.startsWith('/usos') = false.

Fix con patron activePrefix (Option A del research — mas limpio y extensible):

1. En `src/lib/nav.ts`:
   - Agregar campo `activePrefix?: string` al type NavItem
   - Agregar `activePrefix: '/uso'` al item de Usos (solo ese item lo necesita)
   - Mantener `href: '/usos'` sin cambiar (para que el link de navegacion siga apuntando a /usos)

```typescript
export type NavItem = {
  readonly href: string
  readonly label: string
  readonly icon: string
  readonly activePrefix?: string
}

export const NAV_ITEMS: readonly NavItem[] = [
  { href: '/usos', label: 'Usos', icon: 'LayoutGrid', activePrefix: '/uso' },
  { href: '/tecnologias', label: 'Tecnologías', icon: 'Cpu' },
  { href: '/personalizacion', label: 'Personalización', icon: 'Palette' },
  { href: '/cuellos', label: 'Cuellos', icon: 'Shirt' },
] as const
```

2. En `src/components/nav-links.tsx` linea 35:
   - Cambiar `const isActive = pathname.startsWith(item.href)` a:
   - `const isActive = pathname.startsWith(item.activePrefix ?? item.href)`

Esto hace que:
- `/usos` -> startsWith('/uso') = true (OK: listado de categorias)
- `/uso/sudaderas-chaquetas-pantalones` -> startsWith('/uso') = true (OK: pagina de categoria)
- `/tecnologias` -> startsWith('/tecnologias') = true (sin activePrefix, usa href)
