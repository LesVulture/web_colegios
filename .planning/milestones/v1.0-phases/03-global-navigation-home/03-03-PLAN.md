Crear `src/app/usos/page.tsx` como Server Component:

**Metadata:**
```typescript
export const metadata: Metadata = {
  title: 'Usos - Lafayette Uni For Me',
  description: 'Categorías de uso para uniformes escolares',
}
```

**Layout:**
- Container: `mx-auto max-w-7xl px-4 lg:px-8 py-8 lg:py-12`
- Título: `<h1>` con "Categorías de Uso" en `text-3xl lg:text-4xl font-heading font-semibold text-foreground`
- Directo al grid después del título (decisión locked: sin intro ni hero)
- Margen entre título y grid: `mt-8`

**Grid de 8 categorías:**
- `grid grid-cols-2 lg:grid-cols-4 gap-4 lg:gap-6` (4 columnas x 2 filas en desktop, per decisión locked)
- Import `CATEGORIES` de `@/lib/content` y `CATEGORY_STYLE_MAP` de `@/lib/content/styles`
- Para cada categoría en CATEGORIES, renderizar una card:
  - Es un `<Link>` de next/link apuntando a `/uso/${category.id}`
  - Obtener colores: `const colors = CATEGORY_STYLE_MAP[category.id]`
  - Aplicar `${colors.bg} ${colors.fg}` como clases del contenedor (fondo completo del color, decisión locked)
  - Clases de la card: `block rounded-lg p-6 lg:p-8 transition-all duration-200 hover:scale-[1.02] hover:shadow-lg cursor-pointer`
  - Height mínimo: `min-h-[140px] lg:min-h-[160px]` para que las cards sean visualmente sustanciales
  - Contenido de la card (per discretion: nombre + conteo de telas):
    - Nombre de categoría: `<h2>` con `text-lg lg:text-xl font-heading font-semibold`
    - Conteo de telas: `<p>` con `text-sm opacity-80 mt-2`. El conteo se obtiene de `category.fabricIds.length`. Texto: `${count} telas` (ej: "9 telas", "5 telas")
    - Descripción opcional: si `category.description` existe, mostrar debajo del conteo en `text-sm opacity-70 mt-1`
  - NO usar interpolación dinámica de clases Tailwind (pitfall 1 de RESEARCH.md). Las clases vienen completas del mapa estático CATEGORY_STYLE_MAP.

**NOTA IMPORTANTE sobre Tailwind dynamic classes:** Todas las clases como `bg-cat-sudaderas`, `text-cat-sudaderas-fg` etc. ya están en el mapa como strings literales. Tailwind las detectará en el scan. No construir clases con template literals.

  </verify>
